V1 & V2 Root Isolation

Next.js Route Mapping

2.3 Reusable Components
Datasource Architecture

Dedicated Datasource folders hold items for shared pieces (Navigation, Footer, TopNavigation, ContentBlock) preventing data duplication across multi-page views.

2.4 Renderings & Templates
Sitecore Helix Conventions

Strict adherence to Foundation/Feature modularity. Maintained item templates for banners, columns, galleries, sliders, and museum collection features.

2.5 Version 1: GraphQL
Nested Children Queries

Parent components like CollectionHighlights with SlideItem children resolved through native Sitecore GraphQL using inline fragments to fetch all fields in a single query.

2.6 Version 2: Layout Service
Optimized Rendering Resolver

Version 2 resolves nested children directly in the Layout Service response via a custom RenderingContentsResolver, removing the extra GraphQL round-trip.
