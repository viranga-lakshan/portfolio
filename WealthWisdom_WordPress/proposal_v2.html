01. Project Understanding & Technical Objective

Wealth Wisdom provides dedicated financial coaching programmes, requiring a unified digital client hub that combines structured six-week course delivery, interactive assignments, and long-term personal financial tracking. Your existing foundation uses WordPress, WooCommerce, and PayPal. Your objective is to expand this into a secure, intuitive Client Portal, LMS, and Financial Snapshot Dashboard that coaches can manage independently without technical friction, while ensuring sensitive client balance sheets remain strictly protected and preserved.

My Architectural Approach in Brief:

• Lean WordPress Ecosystem: Combine LearnDash LMS with your existing WooCommerce and PayPal setup for automated enrolment, deliberately avoiding secondary membership plugins to eliminate conflicting access rules.
• Single Custom Engine: Build one lightweight plugin (Wealth Wisdom Portal) handling the customized client dashboard, private document downloads, and the dedicated financial snapshot tracking engine.
• Permanent Financial Data Layer: Client financial snapshots and learning histories are gated strictly by user authentication, never by course access expiry. Expired clients retain full access to their balance sheets and can log in to renew anytime.

Background & Transferable Competencies:

My recent production builds were engineered on other enterprise platforms—including the Holsten Arabia multilingual portal on Umbraco CMS, a multi-tenant e-commerce backend with per-tenant data isolation on PHP 8 and Laravel Lumen, and an enterprise gate-pass platform on Java and Spring Boot for DIMO Lanka. The core architectural disciplines required for Wealth Wisdom—strict per-user data isolation, subscription and access lifecycle enforcement, role separation, audit logging, and historical data preservation—transfer directly to this WordPress build. This specific implementation will be built entirely within native WordPress standards. To eliminate technical risk, I am prepared to demonstrate a working proof-of-concept of the financial snapshot module on a staging site before contract sign-off.

03. Recommended Technical Approach & Lean Stack

The core architectural principle for this system is: fewest possible plugins, single source of truth for user access, and one dedicated custom plugin for business logic that standard tools cannot fulfill.

System Layer Recommended Tool Architectural Rationale & Operational Mechanics
LMS Core LearnDash LMS
(Tutor LMS evaluated)		 While Tutor LMS is viable, LearnDash is recommended due to its deep WooCommerce integration, robust group management, and mature assignment review pipelines. Coaches utilize the LearnDash Group Leader role to review and approve submitted worksheets without needing full administrator access.
Payments & Access WooCommerce + LearnDash Integration Native WooCommerce integration links purchases directly to course enrolment via PayPal. We deliberately avoid a secondary membership plugin to prevent dual-system synchronization failures and access state conflicts.
Cohort Access Control Custom Cohort Handler
(Custom Extension)		 LearnDash calculates course expiry from enrolment timestamp by default. We introduce a custom hook enabling access to run for 10 weeks calculated from an agreed programme cohort start date, supporting scheduled group intakes.
Subscription Extensions Option A vs. Option B
(Two Viable Paths)		 Option A: WooCommerce Subscriptions extension enabling automated monthly recurring billing via PayPal.
Option B (Recommended for Launch): Standard one-time "Access Extension" products where clients renew on demand, adding automated recurring billing later. This avoids complex recurring subscription overhead on day one.
Portal & Financials Custom Plugin:
Wealth Wisdom Portal		 Custom WooCommerce My-Account endpoint rendering the wireframe dashboard. Financial tracking utilizes dedicated custom database tables (ww_financial_snapshots) storing timestamped, immutable financial balance sheets. Data is gated solely by login, ensuring client records remain intact after course expiry.
Private Documents Protected Storage Handler Client documents and coach assignments are stored outside public media paths, served exclusively through an authenticated PHP gateway (readfile() with strict permission checks), preventing direct URL indexing.

Roles & Access Governance Matrix:

User Role Learning & Course Materials Client Financial Records Resource & Document Management
Client Access enrolled course during active 10-week window; upload assignments. Full edit and view rights to own balance sheet; historical snapshot comparison. View assigned worksheets; download and upload to private personal folder.
Coach (Group Leader) Review and grade submitted assignments for assigned cohort clients. View financial summaries for assigned clients only (if authorized by client). Assign specific library resources to individual clients or assigned groups.
Administrator Create and edit courses, lessons, topics, quizzes, and pricing products. System administration; access to client financial records is logged for audit. Central library management; full administrative override and export rights.

05. Security Architecture, Data Isolation & POPIA Alignment

Because Wealth Wisdom handles sensitive personal financial data, security cannot rely on generic assumptions. I enforce a strict defensive architecture across the application layer:

Security Domain Implemented Standard Engineering Protection Mechanism
Financial Field Encryption Application-Level Libsodium Sensitive financial data fields are encrypted at the application level using PHP Libsodium before database insertion. The encryption key is isolated outside the database in server environment variables. (No WordPress plugin provides automated database encryption at rest).
Data Access Isolation Strict User-ID Validation All database queries utilize wpdb-prepared statements with mandatory session user-ID checks. Zero client balance sheet queries can execute without verified ownership validation.
Endpoint Security Solid Security Suite + Cloudflare Deployment of Solid Security (one dedicated suite—never running conflicting security tools) coupled with Cloudflare web application firewall, enforcing HTTPS, brute-force locking, and request sanitation.
Authentication Security Two-Factor Authentication (2FA) Enforced 2FA for all administrative and coaching accounts; optional 2FA for clients. Strict session timeouts for inactive dashboard tabs.
Audit Logging Internal Security Audit Trail Every administrative inspection or coach review of client balance sheet records is written to an immutable internal audit log.
Caching & Leakage Policy Strict Portal Exclusions All client portal endpoints (/my-account/portal/*) and logged-in user requests are strictly excluded from page caching to prevent cached financial data leaks. No caching plugin bloat.
POPIA Regulatory Compliance Data Privacy Standards Alignment with South African POPIA regulations: transparent privacy consent notice on signup, client self-service data export, and standard account deletion procedures.
