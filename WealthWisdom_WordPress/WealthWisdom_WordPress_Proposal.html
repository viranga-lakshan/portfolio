03. Architecture, Plugin Selection & Custom Code Boundary

To keep long-term maintenance straightforward and prevent software fragility, I strictly adhere to your preference: leverage established, battle-tested WordPress plugins for standard functionality, and write clean, bespoke PHP extensions only where standard plugins fall short.

Functional Domain Recommended Component Implementation Logic & Operational Rationale
Learning Management (LMS) LearnDash LMS Handles 6-week structured curricula, video embeds, assignment upload dropzones, and coaching evaluation workflows. Native WooCommerce integration automatically enrols clients upon checkout.
Membership & Access Control MemberPress / WooCommerce Memberships Enforces the 10-week time-limited access window calculated from the course start date. Automates expiry reminders, subscription renewals, and keeps expired users intact without data loss.
Personalized Client Dashboard Custom Endpoint on WooCommerce My-Account Extends WooCommerce's core account architecture with custom template overrides. Renders the 6-tile layout matching your wireframe without bloating your site with third-party page builders.
Financial Snapshot Engine Bespoke WordPress Plugin (PHP & MySQL) Custom Developed: Dedicated custom database tables (wp_ww_snapshots) capturing timestamped records of income, expenses, assets, liabilities, and calculated surplus. Completely independent of course lifecycles.
Individual Resource Assignment Custom Post Type + User Meta Mapping Custom Developed: Simple WordPress admin interface allowing coaches to select any media or worksheet and link it directly to a specific user's dashboard tab.
Data Security & Isolation Wordfence Security + Database Hardening Parameterized SQL queries, nonces on all form submissions, strict capability checks preventing horizontal user data access, and two-factor authentication (2FA) for coach/admin logins.
