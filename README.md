## 🚀 How to Publish to GitHub Pages (Free Live Website)

### Option 1: Using GitHub Desktop / Git CLI
1. Initialize a Git repository in this folder (or create a new GitHub repo named `viranga-lakshan.github.io` or `portfolio`).
2. Commit and push `index.html` to the `main` branch:
   ```bash
   git init
   git add index.html README.md
   git commit -m "Initial portfolio release"
   git branch -M main
   git remote add origin https://github.com/viranga-lakshan/portfolio.git
   git push -u origin main
   ```
3. Go to your repository on GitHub:
   - Click **Settings** ➔ **Pages** (in the left sidebar).
   - Under **Build and deployment** ➔ **Source**, select **Deploy from a branch**.
   - Under **Branch**, select `main` and `/ (root)`, then click **Save**.
4. In 1 minute, your portfolio will be live at:  
   👉 **`https://viranga-lakshan.github.io/portfolio/`**

---

### Option 2: Drag and Drop via GitHub Web
1. Create a new repository on GitHub named `portfolio` (or `viranga-lakshan.github.io`).
2. Click **"uploading an existing file"**.
3. Drag and drop `index.html` into the browser and click **Commit changes**.
4. Go to **Settings > Pages** and enable GitHub Pages on the `main` branch.
