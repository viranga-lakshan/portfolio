Technical Evaluation: Webflow CMS vs. Umbraco 17 LTS

As noted in our technical assessment, both platforms deliver high-performance bilingual experiences. Webflow is our primary recommendation for speed and non-technical publishing; Umbraco 17 LTS is our enterprise alternative for code ownership and large file handling:

Criterion Webflow CMS (Primary Recommendation) Umbraco 17 LTS (ASP.NET Core Alternative) Edge
Initial Delivery Timeline 2–3 weeks: Visual build, zero server plumbing; rapid focus on typographic polish and content taxonomy. 3–4 weeks: Document types, Razor views, local SQLite to SQL deployment pipelines. Webflow
Arabic + English Parity Native Localize: Secondary locale with localized SEO, automatic dir="rtl", and localized typography styling. Language Variants: Built-in multi-culture support per document type; full control over separate RTL stylesheets. Tie
Research Repository & PDFs CMS collections (up to 20k items); native file field capped at 10 MB per PDF (larger white papers linked via Cloudflare R2 / AWS S3). Unrestricted Media Library: No file size limits; native Lucene / Examine full-text search indexing across research papers. Umbraco
Non-Technical Editorial Visual On-Page Editing: Advisory staff and authors update research briefs directly in the browser with minimal training. Backoffice Forms: Clean and structured, but more abstract; requires 1–2 hours initial editor onboarding. Webflow
Hosting & Maintenance Fully Managed SaaS: AWS/Fastly edge CDN, automatic SSL, DDoS protection, zero server patching. Umbraco Cloud or Self-Hosted: Fully managed via Umbraco Cloud Starter, or self-hosted on Azure/.NET host. Webflow (Ease)

Why Webflow for This Mandate (Primary)

  • Advisory Turnaround: 2–4 week delivery window strongly favors an environment where hosting, forms, and CDN are turn-key.
  • Author Autonomy: Economists and research staff publish working papers without requiring ongoing developer retainers.
  • Clean Handover: The workspace transfers directly into Economic Architecture Advisory's name with zero server maintenance.

When to Select Umbraco 17 LTS (Alternative)

  • Large Econometric Reports: If research papers routinely exceed 10 MB and client prefers not to link external Cloudflare R2 URLs.
  • Data Residency & Governance: If sovereign mandates require the site to reside inside dedicated Saudi/GCC Azure instances.
  • Proven Umbraco Expertise: Our lead engineer (Viranga Lakshan) built Holsten Arabia on Umbraco Headless in the Middle East.

Cryptographic Mail Deliverability Suite (econarc.com.sa)

1. Sender Policy Framework (SPF)

DNS TXT

Restricts email sending authority strictly to authorized Google/Microsoft servers, stopping spoofing.

v=spf1 include:_spf.google.com ~all

2. DKIM 2048-Bit Signing

RSA Cryptography

Signs outbound executive emails with a cryptographic key, guaranteeing message integrity in transit.

k=rsa; p=MIIBIjANBgkqhkiG9w0BAQEFAAOCAQ8AMIIBCg...

3. DMARC Policy & Telemetry

Policy Enforcement

Instructs recipient gateways to reject fraudulent mail while routing daily forensic telemetry to security.

v=DMARC1; p=reject; rua=mailto:dmarc@econarc.com.sa

4. DNSSEC & Strict Transport

Root Integrity

DNSSEC signing at registrar level protects .com.sa domain against DNS cache poisoning, with TLS 1.3.
